## 1. 基础物理交互 (Core Physics)

- [x] **1-254 像素保护**：Shader 采样必须执行 `if (h < 0.01 || h > 0.99) discard;` 以彻底移除纯黑/白杂质。
- [x] **3x3 驱动柔化**：严禁直接采样原图作为流光驱动。必须执行 3x3 均值模糊采样，提升质感并消除锯齿。
- [x] **曝光保护 (Tone-Mapping)**：最终输出经过 `1.0 - exp(-effect * 1.5)` 处理，确保高亮处不“爆掉”。
- [x] **底图 1:1 绝对诚信**：当 `u_is_base == 1` 时，严禁任何 UV 扭曲 or 物理偏移。
- [x] **50% 锐度保护**：WebGL 渲染层必须锁定 50% 锐度偏移保护，确保边缘清晰度符合工业基准。
- [x] **双模式渲染协议 (Dual-Mode)**：Shader 必须支持 `u_mode` 实时切换。Mode 0 为高亮白光流影；Mode 1 为全息虹彩 (Rainbow)。**[调优参数]**：虹彩模式饱和度必须锁定在 **0.7**，且色彩变幻频率与 `u_time` 严格等比例耦合。

## 2. 图层与资产逻辑 (Assets & Layers)

- [x] **重复导入解锁**：`file-input` 在 `onchange` 后必须立即执行 `e.target.value = ''`，支持同一文件多次载入。
- [x] **首图自动铺满 (Auto-Fit)**：首张素材载入后，视口必须自动计算 Scale（约 85% 填充），严禁默认 1:1 怼脸。
- [x] **底图自动让渡协议**：**[核心]** 当图层数量 = 1 时，该层必须保留光效。当图层数量 > 1 时，底图（索引 0）的 `u_bright` 必须自动设为 0。
- [x] **位置即底图协议 (Location-based Base)**：有且仅有一个底图，列表最下方的图层（索引 0）自动作为底图。被拖动到该位置的图层默认开启可见，但允许手动关闭。
- [x] **物理排序手柄**：图层左侧必须有 `drag-handle`，且支持 PointerCapture 实时平滑物理排序。
- [x] **入位底图强制激活**：图层被拖动至索引 0（列表底部）晋升为底图时，系统必须自动将其 `visible` 设为 `true`，确保地基稳固。
- [x] **底图变更视角自适应**：当底图对象（索引 0）由于排序或载入发生更替时，必须自动触发视口复位（85% 填充），严禁出现因分辨率不匹配导致的“怼脸”现象。
- [x] **载入零延迟**：首张素材载入时必须瞬间显示在计算后的 Scale 位置。同时，侧边栏图层卡片进入时严禁使用 Scale 缩放动画，仅允许轻微位移或直接显示。
- [x] **全量光效同步 (Global Sync)**：图层卡片内的模式切换按钮具有全局效力。点击任一图层的“白光/全息”按钮，必须同步更新内存中所有图层的 `mode` 状态，确保视觉风格高度统一。
- [x] **图层物理销毁 (Layer Deletion)**：每个图层卡片底部必须配备红色垃圾桶样式的 `delete-layer-btn`。点击瞬间从 `layers` 内存数组中物理移除，并同步触发 `updateUI()` 与 `renderCanvas()`，确保内存与视觉实时同步。
- [x] **全域拖拽导入协议 (Drag & Drop Protocol)**：导入区必须支持物理拖拽松手导入，且在拖拽经过时有明显的 `drag-active` 视觉反馈（缩放 + 变色）。支持单次批量拖入多个文件。

## 3. 专业抠图工作流 (Keying Workflow)

- [x] **8倍物理放大镜**：吸色预览区配备独立 Canvas 渲染的像素级放大镜，支持 Crosshair 精准定位。**[核心细节]**：放大镜必须设置 `pointer-events: none` 以确保点击穿透；渲染模式强制锁定 `pixelated` 以保证像素诚信。
- [x] **吸色智能回弹**：检测到用户吸色且当前容差为 0 时，系统必须自动将容差设为 **10**，提供即时视觉反馈。
- [x] **实时色值探测 (Real-time Probe)**：鼠标在抠图预览区移动时，Hex 输入框必须实时显示当前指向像素的 16 进制色值。
- [x] **十六进制强制同步与容错 (Hex Sync & Tolerance)**：Hex 输入框 must 支持双向同步。**[核心容错]**：支持省略 `#` 号输入（系统必须自动补齐），且输入后自动执行 `toUpperCase()` 保持格式统一。
- [x] **物理色块实时联动**：输入框左侧的视觉预览色块必须随 Hex 值实时变化，确保色值与视觉表现 100% 物理对齐。
- [x] **抠图缩略图复位 (Thumbnail Reset)**：在每个图层缩略图右上角配备绝对定位的**蓝色旋转图标按钮**，点击执行该图层的局部视口复位（回归到 1:1 原始预览状态）。
- [x] **抠图参数重置 (Keying Reset)**：底部配备红色 `clear-keying-btn` (叉号)，点击瞬间重置容差为 10、清除 Shader 状态，**并自动联动还原缩略图视口 (Scale 1:1, Offset 0)**。
- [x] **全局视口复位 (Global Viewport Reset)**：在主视口右上角配备“复位视图”按钮，点击执行全局视口复位（回归到 85% Auto-Fit 铺满状态）。

## 4. 极致交互细节 (Focus Protocol)

- [x] **点击即控与视觉反馈 (Focus Protocol)**：点击时间轴上的任何数字必须同时触发 **[自动暂停]** 与 **[全量对焦 select()]**。同时必须提供物理视觉反馈：聚焦态下输入框背景自动切换为微光色 (`rgba(59, 130, 246, 0.08)`) 并伴随 1px 容器边界，确保用户明确其可编辑状态。
- [x] **无极滚轮微调**：数字输入框监听 `onwheel`，支持以 0.1 为步长的滚轮调节。
- [x] **AB 联动防撞**：A/B 点之间保持 0.01 最小物理间距。
- [x] **速率上下限锁定**：播放速率输入框与滑块严格限制在 **[0.1x - 2.0x]** 区间，严禁出现 zero 速率或非法超大数值。
- [x] **全量数值双向联动 (Value-Slider Sync)**：时间轴、播放速率、循环区间等所有“数字+滑块”组合，必须严格执行双向同步逻辑：拖动滑块即更新数字，修改数字即瞬间物理同步滑块位置。
- [x] **全量确认协议 (Commit Protocol)**：所有文本/数字输入框必须监听 `Enter` 键。点击回车必须立即执行 `blur()` 物理脱焦并同步数据，严禁输入后必须点击空白处才能生效。
- [x] **边界硬锁定协议 (Boundary Locking)**：所有数值输入框（速率、时间、循环点、容差）必须在 `onchange` 瞬间执行 `Math.max/min` 物理钳制。严禁由于用户输入导致数值溢出物理定义域。
- [x] **单位自动诚信补全 (Unit Integrity Protocol)**：所有具备物理单位的输入框（速率 X, 比例 %, 颜色 #），必须具备“输入容错”与“自动回显”能力。用户允许省略单位输入，但在 `onchange` 瞬间，系统必须物理强制补全对应单位，严禁出现“裸奔”的纯数字。

- [x] **物理级缝合 (Seamless Stitching)**：切换按钮必须作为侧边栏的“延伸 (Extension)”而非悬浮。严禁 `border-left`，通过 `margin-left: -1px` 压住主体边框，消除断层感。

- [x] **冰川玻璃 (Glacier Glass)**：背景模糊锁定 40px，使用动态 Aurora 背景。主视口严禁使用棋盘格背景。
- [x] **复位图标指向**：视口复位必须使用 **Rotate-CCW (逆时针旋转)** 图标。
- [x] **主标视觉物理规格 (Main Logo Spec)**：

  - **字符防护协议**：必须包含 `padding-right: 0.05em` 与 `margin-right: -0.05em` 的物理补偿，确保字形溢出时不被容器裁剪。

- [x] **视口随动中心协议 (Viewport-Adaptive Centering)**：主标 (Logo) 必须基于 `flex-grow` 视口容器的中心定位，严禁使用相对于全屏的固定坐标。当侧边栏折叠/展开导致可用空间变化时，主标必须实时物理平移，确保始终处于“当前有效视口”的正中心。

- [x] **渲染地基同步 (Canvas Sync)**：首张素材载入时，Canvas 物理像素宽高必须强制同步为素材原始宽高，严禁使用默认 Canvas 尺寸导致黑屏。
- [x] **交互解耦协议 (Interaction Decoupling)**：侧边栏缩略图支持私有滚轮缩放与鼠标拖拽位移。主视口与缩略图的 `Scale` 与 `Offset` 变量必须物理隔离，严禁任何形式的逻辑黏连。确保缩略图仅供精准吸色使用，其交互动作绝不干扰主视口视觉状态。同时遵循“局部橡皮筋协议”，严禁素材脱离视野。
- [x] **弹性视口回弹 (Elastic Snap-back)**：主视口拖拽具备物理弹性，严禁将图片彻底拖离视野。超出安全边界（150px 缓冲）后自动执行阻尼回弹。
- [x] **格式友好申明**：侧边栏“导入素材”按钮下方必须清晰标注支持 PNG, JPG, WEBP 格式。
- [x] **全量变量解耦与视觉全量同步协议 (Theme Integrity & Global Sync)**：
  - **零硬编码**：严禁在 CSS/JS 中使用 `bg-white/10` 等硬编码类名。所有背景、边框、文字必须桥接 `var(--glass-bg)`, `var(--glass-border)`, `var(--on-surface)`。

## 7. 架构与稳定性 (Architecture)

- [x] **预乘透明度**：纹理载入必须开启 `UNPACK_PREMULTIPLY_ALPHA_WEBGL`，彻底消除 PNG 半透明边缘的黑色脏影。
- [x] **层级序反向映射**：UI 列表“从上到下”的物理顺序必须精准对应 WebGL “从后到前”的渲染深度序。
- [x] **异步初始化安全**：图片 `onload` 必须作为 WebGL 纹理生成的唯一触发源，严禁出现空纹理占用。
- [x] **缩略图物理映射**：缩略图 `drawImage` 必须基于 `layer.img` 的原始物理尺寸进行 `sw/sh` 逆向计算，确保缩放中心不偏移。
- [x] **叠加层物理混合协议 (Layered Blending)**：为了保证多图层光效的纯净度，Shader 必须执行逻辑分离：底图（isBase=1）输出 `base + effect`；叠加层（isBase=0）仅输出 `effect`。同时，WebGL 混合函数强制锁定为 `gl.blendFunc(gl.ONE, isBase ? gl.ZERO : gl.ONE)`。
